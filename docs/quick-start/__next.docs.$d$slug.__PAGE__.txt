3:T21d6,<p>KIRA reads your source code and writes down what it means for the people who use your product.
Those notes become a knowledge base, and the knowledge base answers questions.</p>
<p>Five minutes end to end. No database, no vector store, no second API key.</p>
<h2>Install</h2>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">npm</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> install</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> -g</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> askkira</span></span>
<span class="line"><span style="--shiki-light:#D73A49;--shiki-dark:#F97583">export</span><span style="--shiki-light:#24292E;--shiki-dark:#E1E4E8"> ANTHROPIC_API_KEY</span><span style="--shiki-light:#D73A49;--shiki-dark:#F97583">=</span><span style="--shiki-light:#24292E;--shiki-dark:#E1E4E8">sk-ant-…</span></span></code></pre><p>The SDK also accepts <code>ANTHROPIC_AUTH_TOKEN</code>, or a profile from <code>ant auth login</code> — you do not have
to use a raw key.</p>
<div class="callout tint-brand"><div class="callout-label">Note</div><div class="callout-body"><p>If a proxy sets <code>ANTHROPIC_BASE_URL</code>, remember the SDK appends <code>/v1/messages</code> to it. A base URL
that already ends in <code>/v1</code> returns 404 on every call.</p>
</div></div><h2>1. See what it proposes</h2>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF">cd</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> your-project</span></span>
<span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> init</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> --dry-run</span></span></code></pre><p>Writes nothing. Prints one row per proposed area with the route it derived from your router, so
you can judge the map before anything is generated:</p>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span>routes found under: src/app</span></span>
<span class="line"><span></span></span>
<span class="line"><span>domains          end_user   /project/:id/domains   src/app/project/[id]/domains</span></span>
<span class="line"><span>billing          end_user   /billing               src/app/billing</span></span>
<span class="line"><span>login            end_user   /login                 src/app/login</span></span></code></pre><h2>2. Write the config, then edit it</h2>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> init</span></span>
<span class="line"><span style="--shiki-light:#24292E;--shiki-dark:#E1E4E8">$EDITOR .kira/config.yaml</span></span></code></pre><div class="callout tint-brand"><div class="callout-label">Important</div><div class="callout-body"><p>This is the ten minutes that matter. The area map is the highest-value human input in the whole
system. Merge what belongs together, delete what has nothing user-facing, and give each area a
name your users would recognise. See <a href="../areas/">Areas</a>.</p>
</div></div><h2>3. Extract</h2>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> extract</span></span></code></pre><pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span>› domains — 6 files, 2 batch(es), end_user</span></span>
<span class="line"><span>›   batch 1/2 → 12 fact(s)</span></span>
<span class="line"><span>›   batch 2/2 → 9 fact(s)</span></span>
<span class="line"><span>✓ domains — 21 fact(s) written</span></span></code></pre><p>Facts land in <code>.knowledge/</code> as one markdown file each. Commit them — the pull request is where a
human approves what a customer will eventually read.</p>
<p>Extraction is a batch job, not an interactive one: expect minutes per area, and re-runs skip every
area whose sources have not changed.</p>
<h2>4. Ask</h2>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> ask</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "how do I connect a domain I already own?"</span></span></code></pre><p>The answer streams to stdout and everything else to stderr, so this gives you just the answer:</p>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> ask</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "…"</span><span style="--shiki-light:#D73A49;--shiki-dark:#F97583"> 2></span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF">/dev/null</span></span></code></pre><p>Pass the reader&#39;s context when you have it — the screen they are on, and what they are entitled to:</p>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> ask</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> "how do I remove this?"</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> --route</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> /project/42/domains</span><span style="--shiki-light:#005CC5;--shiki-dark:#79B8FF"> --plan</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> free</span></span></code></pre><h2>5. Keep it honest</h2>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span style="--shiki-light:#6F42C1;--shiki-dark:#B392F0">kira</span><span style="--shiki-light:#032F62;--shiki-dark:#9ECBFF"> status</span></span></code></pre><pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span>Area       Files  Facts  Bound.  Route  State</span></span>
<span class="line"><span>─────────  ─────  ─────  ──────  ─────  ───────────</span></span>
<span class="line"><span>domains        6     21       3     21  fresh</span></span>
<span class="line"><span>billing        4     12       2     12  stale</span></span>
<span class="line"><span>─────────  ─────  ─────  ──────  ─────  ───────────</span></span>
<span class="line"><span>TOTAL         10     33       5     33</span></span></code></pre><p><code>stale</code> means the sources changed since the facts were written. Wire <code>kira extract</code> into CI on
merge and the drift stays visible instead of silent.</p>
