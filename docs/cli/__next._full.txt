16:T2cfa,<p>Four commands. <code>ask</code> streams its answer to stdout and everything else to stderr, so
<code>kira ask … 2&gt;/dev/null</code> gives you exactly the answer and nothing else.</p>
<h2><code>kira init [dir] [--dry-run] [--force]</code></h2>
<p>Scans a repository and writes <code>.kira/config.yaml</code> with an area map proposed from its structure.
<code>dir</code> defaults to the current directory.</p>
<table>
<thead>
<tr>
<th>Flag</th>
<th>Effect</th>
</tr>
</thead>
<tbody><tr>
<td><code>--dry-run</code></td>
<td>Print the proposal and write nothing.</td>
</tr>
<tr>
<td><code>--force</code></td>
<td>Replace an existing config.</td>
</tr>
</tbody></table>
<h2><code>kira extract [--area &lt;id&gt;] [--force]</code></h2>
<p>Reads each area and writes facts into <code>.knowledge/</code>.</p>
<table>
<thead>
<tr>
<th>Flag</th>
<th>Effect</th>
</tr>
</thead>
<tbody><tr>
<td><code>--area &lt;id&gt;</code></td>
<td>Only this area. Repeatable.</td>
</tr>
<tr>
<td><code>--force</code></td>
<td>Re-extract even when the sources have not changed.</td>
</tr>
</tbody></table>
<p>Areas are incremental by content hash: an unchanged area is skipped without a single API call. An
area&#39;s directory is cleared before it is rewritten, so a fact whose source disappeared does not
linger.</p>
<div class="callout tint-flag"><div class="callout-label">Warning</div><div class="callout-body"><p>Extraction is where the money goes. It scales with the size of the areas you configured, runs at
<code>high</code> effort by default, and takes minutes rather than seconds. Start with one area and
<code>--area</code> while you tune the map.</p>
</div></div><h2><code>kira status</code></h2>
<p>Facts, boundaries, routes and staleness per area — no API calls, so it is free and instant.</p>
<pre class="shiki shiki-themes github-light github-dark" style="--shiki-light:#24292e;--shiki-dark:#e1e4e8;--shiki-light-bg:#fff;--shiki-dark-bg:#24292e" tabindex="0"><code><span class="line"><span>Area       Files  Facts  Bound.  Route  State</span></span>
<span class="line"><span>─────────  ─────  ─────  ──────  ─────  ───────────</span></span>
<span class="line"><span>domains        6     21       3     21  fresh</span></span>
<span class="line"><span>billing        4     12       2     12  stale</span></span>
<span class="line"><span>login          1      0       0      0  not yet run</span></span>
<span class="line"><span>─────────  ─────  ─────  ──────  ─────  ───────────</span></span>
<span class="line"><span>TOTAL         11     33       5     33</span></span></code></pre><p><code>stale</code> means the area&#39;s sources changed since its facts were written. It also reports facts
belonging to areas no longer in the config, and any file under <code>.knowledge/</code> that could not be
parsed — one broken file is listed rather than failing the whole base.</p>
<h2><code>kira ask &quot;&lt;question&gt;&quot; [options]</code></h2>
<table>
<thead>
<tr>
<th>Option</th>
<th>Effect</th>
</tr>
</thead>
<tbody><tr>
<td><code>--route &lt;path&gt;</code></td>
<td>The screen the reader is on. Boosts facts that live there.</td>
</tr>
<tr>
<td><code>--plan &lt;name&gt;</code></td>
<td>The reader&#39;s plan. Facts gated away from them are dropped.</td>
</tr>
<tr>
<td><code>--role &lt;name&gt;</code></td>
<td>The reader&#39;s role. Same.</td>
</tr>
<tr>
<td><code>--flag &lt;name&gt;</code></td>
<td>An enabled feature flag. Repeatable.</td>
</tr>
<tr>
<td><code>--audience &lt;a&gt;</code></td>
<td>Read as <code>end_user</code>, <code>operator</code> or <code>developer</code>.</td>
</tr>
<tr>
<td><code>--limit &lt;n&gt;</code></td>
<td>Facts to retrieve. Default 5.</td>
</tr>
<tr>
<td><code>--include-low</code></td>
<td>Include facts the extractor was unsure about.</td>
</tr>
<tr>
<td><code>--raw-query</code></td>
<td>Score the question as typed, skipping the rewrite hop.</td>
</tr>
<tr>
<td><code>--json</code></td>
<td>Emit the answer and retrieval detail as JSON.</td>
</tr>
<tr>
<td><code>--no-sources</code></td>
<td>Do not print which facts were used.</td>
</tr>
</tbody></table>
<p>Without <code>--plan</code> / <code>--role</code> / <code>--flag</code> no gating happens at all: an unknown reader is never
gated, because a CLI or an unauthenticated widget must not answer less than it knows.</p>
